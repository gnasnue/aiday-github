# Context Save — 작업 맥락 저장

다음 세션(또는 다른 환경의 세션)이 이어받을 수 있도록 현재 작업 맥락을 저장한다.

## 저장 위치

`docs/context/YYYY-MM-DD-<주제>.md` 로 저장하고, `docs/context/LATEST.md` 를 같은 내용으로 덮어쓴다 (LATEST.md가 항상 최신 스냅샷).

## 저장 내용

```markdown
# Context — <주제> (YYYY-MM-DD)

## 지금 하던 일
현재 작업의 목표와 진행 단계. 브랜치명, uncommitted 변경 여부.

## 완료된 것
이번 세션에서 끝낸 일 (커밋 해시 포함).

## 결정 사항
논의 끝에 내린 결정과 그 이유. 기각된 대안도 한 줄씩.

## 다음 할 일
우선순위 순. 각 항목에 착수 지점(파일:라인)을 명시.

## 주의사항
다음 세션이 모르면 실수할 함정 (API 제약, 미해결 이슈, 임시 코드 위치 등).
```

## 규칙

- 대화를 요약하는 게 아니라 **다음 세션이 바로 착수할 수 있는 상태**를 만드는 것이 목적이다. "논의했다"가 아니라 "X로 결정, 이유는 Y"로 쓴다.
- uncommitted 변경이 있으면 저장 파일에 명시하고, 커밋해 둘지 사용자에게 확인한다.
- 저장 후 git에 커밋할지 사용자에게 확인한다 (원격 세션에서 복원하려면 푸시 필요).
