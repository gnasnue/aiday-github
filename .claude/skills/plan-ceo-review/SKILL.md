# CEO Plan Review — 전략·스코프 리뷰

계획 또는 현재 변경사항을 CEO 관점에서 검토한다. 질문은 하나다: **"이것이 지금 만들 가치가 있는가?"**

## 진행 순서

### 시스템 감사 (Pre-Review System Audit)
리뷰 전에 현재 상태를 파악해 리포트 서두에 기록한다:
- 현재 브랜치, uncommitted 변경 파일과 변경 내용 요약
- `git log --oneline -10` 최근 커밋 이력
- 코드를 읽다가 즉시 발견된 문제 (스코프와 무관해도 기록)

### Step 0: Nuclear Scope Challenge
- **0A. Premise Challenge** — 해결하려는 문제가 올바른 문제인가? 아무것도 안 하면 무슨 일이 생기는가?
- **0B. Cheaper Alternative** — 같은 결과를 절반의 작업으로 얻는 방법은 없는가?
- **0C. Scope Cut** — 계획에서 지금 잘라낼 수 있는 부분은 무엇인가?

### Step 1: 전략 정합성
- MANIFESTO.md의 원칙과 README.md의 로드맵 Phase에 비추어 이 작업의 위치를 평가한다.
- MVP 단계임을 항상 상기한다: 사용자 검증 전에 과투자하고 있지 않은가?

### Step 2: 판정
다음 중 하나로 결론 낸다:
- **PROCEED** — 계획대로 진행
- **HOLD SCOPE** — 진행하되 스코프 확장 금지, 잘라낼 항목 명시
- **CUT** — 계획 축소, 남길 최소 범위 명시
- **STOP** — 진행하지 않음, 사유 명시

## 산출물

리포트를 `docs/reviews/YYYY-MM-DD-ceo-review-<주제>.md`로 저장한다. 서두에 다음 메타데이터를 포함한다:

```
> Generated by `/plan-ceo-review` on YYYY-MM-DD
> Branch: `<branch>` | Mode: **<판정>**
> Repo: gnasnue/aiday-github
```

이 스킬은 리뷰만 한다 — 코드 수정은 하지 않는다.
