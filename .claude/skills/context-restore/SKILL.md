# Context Restore — 작업 맥락 복원

/context-save 로 저장된 맥락을 읽어 이전 작업을 이어갈 준비를 한다.

## 진행 순서

1. `docs/context/LATEST.md` 를 읽는다. 특정 날짜/주제를 지정받았으면 `docs/context/` 에서 해당 파일을 찾는다. 파일이 없으면 그 사실을 보고하고, 대신 `git log`와 CHANGELOG.md로 최근 상태를 추정해 준다.
2. **현재 상태와 대조**: 저장 시점 이후 변한 것을 확인한다.
   - 저장된 브랜치가 아직 존재하는가, 머지되었는가 (`git log`, `git branch -a`)
   - "다음 할 일"의 착수 지점(파일:라인)이 여전히 유효한가
3. **복원 보고**: 다음을 요약해 제시한다.
   - 지난 세션의 목표와 멈춘 지점
   - 저장 이후 변경된 것 (있다면)
   - 다음 할 일 목록 (저장된 우선순위 순, 무효화된 항목은 표시)
4. 사용자 확인 후 첫 번째 항목부터 착수한다.

## 규칙

- 저장된 맥락과 현재 코드가 어긋나면 (예: 다음 할 일이 이미 완료됨) 추측으로 메우지 말고 어긋난 지점을 명시한다.
- 복원만으로 작업을 시작하지 않는다 — 어디부터 이어갈지 사용자 확인을 받는다.
