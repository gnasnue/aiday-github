# Design Consultation — 디자인 시스템 상담

DESIGN.md를 기준으로 디자인 의사결정을 돕는다. 이 스킬은 **코드를 수정하지 않는다** — 답변과 권고가 산출물이다.

## 진행 방식

1. **DESIGN.md 전체를 읽는다.** 답변은 반드시 DESIGN.md의 규정을 인용하며 한다.
2. 질문 유형별 대응:
   - **"이럴 땐 어떤 색/크기/컴포넌트?"** → DESIGN.md에 정의된 값 중에서 고르고, 근거 조항을 인용한다. 정의 밖의 값은 제안하지 않는다.
   - **"DESIGN.md에 규정이 없는데?"** → 기존 원칙(Warm Minimal, restrained color)에서 유도한 안을 제시하고, DESIGN.md에 추가할 초안을 작성해 준다.
   - **"이 규정을 바꾸고 싶은데?"** → 변경이 기존 화면들에 미치는 영향 범위를 조사해 함께 보고한다.
3. 시각적 판단이 필요하면 실제 구현 화면(`npm run dev` 후 스크린샷)을 근거로 삼는다.

## 규칙

- DESIGN.md 수정은 사용자의 명시적 승인 후에만 한다.
- "예쁘다/안 예쁘다"가 아니라 "시스템에 부합한다/어긋난다"로 말한다.
- 사용자 대상(영유아 부모, 아침의 급한 확인)을 항상 판단 기준에 포함한다.
