# AiDay 문제검증 맘테스트 결과
### Problem Validation Mom Test (온라인 설문, n=36)

> 2차 검증(문제·고객군 검증)의 일환으로 진행한 행동 기반 설문입니다.
> Mom Test 방법론에 따라 **사용 의향이 아니라 "최근 7일 / 최근 한 달에 실제로 한 일"**을 물었습니다.
> 1차 가설검증 설문(n=17, [원본](2026-05-사전-가설검증-설문.md))이 페인포인트와 수요의 *방향성*을 확인했다면, 이 조사는 그 페인이 **행동 수준에서 실재하는지**를 확인합니다.

| 항목 | 내용 |
|---|---|
| 조사 목적 | 아침 육아 판단 문제의 실재성 검증 — 의향이 아닌 실제 행동·사건 기준 |
| 조사 방식 | 온라인 설문 (행동·사건 회상 문항, 복수선택 중심) |
| 배포 채널 | 맘카페 · 직장인 커뮤니티 · 기타 SNS |
| 수집 기간 | 2026-07-14 ~ 2026-07-17 (원자료 타임스탬프 기준) |
| 응답자 수 | 36명 — **아빠 19명(52.8%) / 엄마 17명(47.2%)** |
| 자녀 기준 | 응답자가 지정한 자녀 1명 기준 (만 1세 미만 ~ 만 8세 전 구간 분포) |
| 문항 구성 | 11문항 (프로필 4 / 행동 빈도 2 / 사건 회상 3 / 정보·판단 입력 2) |

## 1. 핵심 결과 요약 (Key Findings)

| # | 검증 대상 | 결과 | 판정 |
|---|---|---|---|
| B1 | 아침 환경 확인이 실제 반복 행동인가 | **75.0%**(27/36)가 최근 7일 중 주 3일 이상 등원 준비 전 날씨·기온·미세먼지 확인 (매일 30.6% + 5일 이상 13.9% + 3~4일 30.6%) | ✅ 행동으로 확인 |
| B2 | 판단 실패·재작업 사건이 실제 발생하는가 | **52.8%**(19/36)가 최근 한 달 내 옷차림·컨디션 때문에 재준비·추가 챙김·아이 불편을 1회 이상 경험 | ✅ 행동으로 확인 |
| B3 | 문제를 줄이기 위한 워크어라운드가 존재하는가 | 전날 밤 미리 확인 **41.7%**, 여벌옷·준비물 상비 **33.3%**, 배우자·가족과 역할 분담 **25.0%** — "특별히 하는 것 없음"은 16.7%뿐 | ✅ 행동으로 확인 |
| B4 | 가정 내 아침 준비 담당이 집중되어 있는가 | **주 5일 전담 47.2% vs 0일 19.4%**로 양극화 — 운영 책임이 특정 보호자에게 집중될 가능성을 시사 (응답자 간 분포, 아래 한계 참조) | ✅ 구조 신호 확인 |
| B5 | 판단 과정에 불확실성·인지 부담이 있는가 | 등원·실외활동 여부 고민 36.1%, 등원 후에도 신경 쓰임 22.2%, **"확신은 없었지만 시간이 없어 일단 결정" 13.9%** | ✅ 경험으로 확인 |

**결론:** "아침의 첫 육아 판단"은 의향이 아니라 **행동 데이터로 실재가 확인된 반복 과업**이다. 부모들은 이미 이 문제에 자기만의 해결책(전날 확인·여벌옷 상비·역할 분담)으로 비용을 지불하고 있으며, 이는 Mom Test 기준 문제 실재성의 가장 강한 신호다. 동시에 아침 준비 담당의 양극화 분포는 "가족 운영 책임이 한 사람에게 집중된다"는 상위 문제 가설([PROBLEM-THESIS](../PROBLEM-THESIS.md))의 행동적 흔적을 보여준다.

| 만 1세 | 4 (11.1%) |

| 만 3세 | 3 (8.3%) |

| 만 5세 | 2 (5.6%) |
| 만 6세 | 2 (5.6%) |
| 만 7세 | 4 (11.1%) |
| 만 8세 | 7 (19.4%) |

→ 핵심 타깃(만 1~8세) 전 구간 커버. 만 7~8세가 30.5%로, v2.7.2에서 유지하기로 한 상한 연령대의 응답도 확보됨.

**Q2. 응답자와 자녀의 관계**

| 관계 | 비율 |
|---|---|
| 아빠 | **52.8%** (19명) |
| 엄마 | 47.2% (17명) |

→ 아빠가 절반 이상인 표본. **이 문제가 '엄마의 문제'가 아니라 '아침 준비 담당자의 문제'임을 성별 단정 없이 말할 수 있는 근거.**

**Q3. 최근 7일 중 평일 아침 등원·등교 준비를 직접 담당한 날**

| 응답 | 비율 |
|---|---|
| 주 5일 | **47.2%** |
| 주 3~4일 | 19.4% |
| 주 1~2일 | 13.9% |
| 0일 | 19.4% |

→ **양극화 분포**: 절반 가까이는 매일 전담하고, 5분의 1은 전혀 담당하지 않는다. 전담자와 비담당자가 나뉘는 이 분포는 운영 책임이 특정 보호자에게 집중될 가능성을 시사한다 — 단, 서로 다른 가구의 응답자 간 분포이며 같은 가구의 두 보호자를 짝지어 조사한 것은 아니다.

**Q4. 가구의 돌봄·근무 형태**

| 구분 | 비율 |
|---|---|
| 맞벌이 | **72.2%** |
| 외벌이 | 19.4% |
| 조부모·시터 등과 분담 | 8.3% |

## 3. 행동 빈도 검증

**Q6. 최근 7일 중 등원·등교 준비 전에 날씨·기온·미세먼지를 확인한 날**

| 응답 | 비율 |
|---|---|
| 매일 | 30.6% |
| 5일 이상 | 13.9% |
| 3~4일 | 30.6% |
| 1~2일 | 11.1% |
| 0일 | 13.9% |

→ **주 3일 이상 확인 75.0%.** 환경 확인은 '가끔 하는 검색'이 아니라 **아침 루틴에 편입된 반복 행동**이다.

**Q7. 가장 최근 평일 아침, 옷차림·준비물·케어 결정 시 실제 참고한 것** (복수선택)

| 참고 대상 | 응답 수 (비율) |
|---|---|
| 휴대전화 기본 날씨 앱 | **23 (63.9%)** |
| 네이버·카카오·기상청 등 날씨 정보 | 16 (44.4%) |
| 아이의 당일 컨디션 | 15 (41.7%) |
| 창밖 날씨나 집 밖의 체감 | 14 (38.9%) |
| 어린이집·유치원·학교 공지 | 10 (27.8%) |
| 평소 경험이나 감 | 10 (27.8%) |
| 자녀 본인 또는 배우자·가족의 의견 | 9 (25.0%) |
| 미세먼지·대기질 정보 | 5 (13.9%) |
| 당일 아침 뉴스 일기예보 | 1 (2.8%) |
| 별도로 참고하지 않음 | 1 (2.8%) |

→ 판단 입력이 **환경(날씨 앱·체감) × 아이 상태(컨디션) × 기관 맥락(공지) × 경험(감)**에 파편화되어 있고, 이 결합은 부모의 머릿속에서 이루어진다 — 판단 4축 구조([문제정의 프레임워크](../문제정의-프레임워크-v3.md))와 일치. 기관 공지가 27.8%로 판단 입력에 이미 들어와 있다는 점은 Post-MVP(알림장·공지 통합) 방향의 행동 근거.

## 4. 사건 회상 검증 (최근 한 달)

**Q8. 옷차림·건강·컨디션 때문에 준비를 다시 바꾸거나, 추가로 챙기거나, 아이가 불편해한 횟수**

| 응답 | 비율 |
|---|---|
| 없었음 | 47.2% |
| 1~2번 | 33.3% |
| 3~5번 (주 1회 정도) | 13.9% |

**Q9. 가장 최근 사건의 내용** (복수선택, n=36 기준)

|---|---|

| 전날 밤 미리 날씨·기관 공지 확인 | 15 (41.7%) |
| 가방에 여벌옷·준비물 상비 | 12 (33.3%) |

## 5. 아침 판단 과정의 경험 (최근 7일)

**Q11. 옷차림을 정하고 컨디션을 살피며 챙기는 과정에서 경험한 것** (복수선택)

| 경험 | 응답 수 (비율) |
|---|---|
| 아이에게 직접 물어 의사 확인 | 13 (36.1%) |
| 아이 컨디션 때문에 등원·실외활동 여부 고민 | 13 (36.1%) |
| 겉옷·여벌옷·우산·마스크 등을 추가로 챙김 | 11 (30.6%) |
| 약·보습제 등 건강 물품을 챙길지 고민 | 10 (27.8%) |
| 준비가 적절했는지 등원 후에도 신경 쓰임 | 8 (22.2%) |
| 입히려던 옷을 다른 옷으로 바꿈 | 8 (22.2%) |
| 여러 앱·날씨 정보를 비교 | 7 (19.4%) |
| 준비물을 빠뜨릴 뻔하거나 다시 확인 | 6 (16.7%) |
| 배우자·가족·기관에 다시 물어봄 | 6 (16.7%) |
| 미세먼지·자외선·습도를 따로 확인 | 6 (16.7%) |
| **확신은 없었지만 시간이 없어 일단 결정** | 5 (13.9%) |

→ 아침 판단이 단순한 옷 고르기가 아니라 **의사 확인 → 컨디션 평가 → 환경 대조 → 물품 결정 → 사후 걱정**으로 이어지는 다단계 인지 과업임을 보여준다. "등원 후에도 신경 쓰임"(22.2%)과 "확신 없이 결정"(13.9%)은 판단의 심리 비용(불안·잔류 부담)의 직접 증거.

## 6. 탐색 주제의 분포 — 웨지의 위치 (Q5)

**Q5. 최근 7일 동안 자녀 관련 정보를 찾아보거나 물어본 주제** (복수선택)

| 주제 | 응답 수 (비율) |
|---|---|
| 놀이·체험·나들이 장소 | 21 (58.3%) |
| 식사·간식·영양 | 18 (50.0%) |
| 아이의 건강·증상 | 18 (50.0%) |
| 교육·발달·학습 | 17 (47.2%) |
| 기관 준비물·공지 | 13 (36.1%) |
| 수면·생활 습관 | 13 (36.1%) |
| 날씨·기온에 따른 옷차림 | 8 (22.2%) |
| 날씨·미세먼지에 따른 외출 여부 | 6 (16.7%) |
| 찾아본 적 없음 | 5 (13.9%) |

→ **중요한 해석 포인트:** 옷차림·외출 여부는 '탐색 주제'로는 하위권이지만, Q6에서는 75%가 주 3일 이상 확인하는 행동으로 나타난다. 두 결과를 겹쳐 읽으면 — **옷차림 판단은 '찾아보는 정보'가 아니라 '매일 아침 확인하고 즉석에서 결정하는 루틴'**이다. 검색할 만큼 어려운 문제가 아니라, 검색할 시간도 없이 매일 처리해야 하는 문제라는 뜻이며, "탐색을 늘리는 서비스가 아니라 판단을 완료해 주는 서비스여야 한다"는 제품 원칙의 행동 근거가 된다.

동시에 이 분포는 부모의 운영 판단 수요가 옷차림 너머(건강·준비물·일정·먹거리)로 넓게 존재함을 보여주는 **확장 방향의 신호**이기도 하다 (단, 확장은 장기 가설 — 현재 MVP 범위 아님).

## 7. 시사점 및 제품 반영

1. **문제 실재성 — 행동으로 검증됨.** 1차 설문(n=17)의 "어렵다"(의견)가 이번 조사에서 "확인한다·실패했다·대비한다"(행동)로 재확인됐다. 멘토 반박("이게 큰 문제냐")에 쓸 수 있는 사업 언어: *부모의 75%가 주 3일 이상 이 판단을 반복하고, 절반이 최근 한 달 안에 실제 실패·재작업을 겪었으며, 83%는 이미 자기만의 해결책에 시간을 쓰고 있다.*
2. **담당자 집중 구조의 시사 신호.** 주 5일 전담 47.2% vs 0일 19.4%. 상위 문제("운영 책임의 집중")를 성별 프레임 없이 '담당자 구조'로 말할 수 있게 하는 시사 신호 — 확정 근거는 아니다(응답자 간 분포, 한계 참조). 아빠 52.8% 표본이라는 점이 이 프레임을 강화한다.
3. **판단 4축 구조 재확인.** 참고 대상이 환경·컨디션·공지·경험으로 파편화(Q7) — 프레임워크의 판단 입력 4축과 일치. 기관 공지(27.8%)는 Post-MVP 공지 통합의 행동 근거.
4. **워크어라운드 = 대체 대상.** 전날 확인·아침 확인·여벌옷 상비·역할 분담이 현재의 '수동 해결책'이다. 아이데이의 브리핑은 이 워크어라운드 묶음을 대체하는 것으로 포지셔닝할 수 있고, 베타에서 "브리핑 도입 후 워크어라운드가 줄었는가"를 검증 지표로 쓸 수 있다.
5. **탐색이 아니라 판단.** Q5×Q6 교차 해석 — 옷차림은 검색 주제가 아니라 매일의 즉석 판단. "즉시 실행 가능한 판단 결과 제공" 원칙의 독립적 재확인.

## 8. 조사의 한계 (Limitations)

- **표본**: n=36 편의표본(맘카페·직장인 커뮤니티·SNS 모집). 통계적 일반화 불가 — 문제 실재성의 방향성 검증 목적.
- **절반은 무사건**: Q8에서 47.2%는 최근 한 달 내 사건이 없었다. 문제가 보편적·상시적이라고 단정할 수 없으며, 계절(7월 조사 — 환절기 아님)의 영향 가능성도 있다.
- **응답 일관성**: Q8 "없었음" 17명과 Q9 "해당사항 없음" 13명이 4명 불일치(사건 횟수는 '없음'으로 답하고 사건 내용은 선택한 응답). 사건 경험률은 보수적으로 Q8 기준(52.8%)을 사용한다.
- **상위 문제의 직접 검증 아님**: 이 조사는 아침 판단(웨지)의 실재를 검증한 것이다. "가족 운영 책임의 집중"이라는 상위 문제 전체는 Q2·Q3의 구조 신호와 외부 통계로 뒷받침되는 **가설**로 유지한다.
- **응답자 간 분포**: Q3의 담당 일수 양극화는 서로 다른 가구의 응답자들 사이의 분포다. 같은 가구의 두 보호자를 짝지어 조사한 것이 아니므로, "가구마다 한 사람에게 책임이 집중된다"를 직접 측정한 결과가 아니다 — 가구 단위 집중은 베타 인터뷰(가구 내 역할 분포 문항)에서 보강한다.
- **지불 의사 미검증**: 이 조사에는 WTP 문항이 없다. 지불 의사는 여전히 미검증.
