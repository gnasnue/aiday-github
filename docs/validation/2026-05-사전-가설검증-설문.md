# AiDay 사전 가설검증 인터뷰 결과
### Pre-MVP Hypothesis Validation Interview (온라인 설문, n=17)

> 서비스 기획 초기 단계에서 목업 MVP를 제시하고 온라인(Google Forms)으로 진행한 가설검증 인터뷰입니다.
> 대면 그룹 토의(FGI)가 아닌, 구조화된 문항 기반의 온라인 설문형 사전 인터뷰입니다.

| 항목 | 내용 |
|---|---|
| 조사 목적 | 환경 기반 육아 의사결정 지원 서비스(AiDay)의 문제 가설 및 수요 검증 |
| 조사 방식 | 온라인 설문 (Google Forms), 목업 MVP 화면 제시 후 응답 |
| 조사 시점 | 2026. 5. (설문 집계 기준) |
| 응답자 수 | 17명 (자녀 있음 13명 / 자녀 없음 4명) |
| 대상 | 만 1세~8세 자녀를 둔 부모 중심 |
| 문항 구성 | 5개 섹션 17문항 (기본 정보 / 페인포인트 / 현재 행동 패턴 / 수요 검증 / 중요도 평가) |

---

## 1. 핵심 결과 요약 (Key Findings)

| # | 가설 | 결과 | 판정 |
|---|---|---|---|
| H1 | 부모는 아침 등원 준비 시 옷차림 결정에 어려움을 겪는다 | **76.4%** 어려움 경험 (매우 자주 17.6% + 가끔 58.8%) | ✅ 검증 |
| H2 | 파편화된 환경 정보(미세먼지 등)로 인한 실패 경험이 있다 | **76.4%** 야외활동 낭패 경험 (자주 17.6% + 가끔 58.8%) | ✅ 검증 |
| H3 | 부모는 매일 환경 정보를 탐색하지만 짧은 시간 안에 판단해야 한다 | **88.2%** 하루 10분 이내 사용 (1~3분 64.7%) | ✅ 검증 |
| H4 | 해석·판단을 대신해주는 서비스에 대한 수요가 존재한다 | 사용 의향 **88.2%** (바로 사용 35.3% + 아마 사용 52.9%) | ✅ 검증 |
| H5 | 가장 원하는 기능은 '먼저 알려주는' 알림이다 | **당일 아침 자동 알림 76.5%** (1위), 전날 저녁 알림 64.7% (2위) | ✅ 검증 |

**결론:** "문제는 정보의 부족이 아니라, 파편화된 정보를 내 아이 기준으로 해석·판단해야 하는 반복적 부담이다"라는 핵심 가설이 정량적으로 확인됨. 부모의 하루 첫 육아 의사결정(등원 전 준비 판단)을 지원하는 AiDay의 포지셔닝과 일치.

## 3. 페인포인트 검증

**Q3. 아침 등원 준비 시 옷차림 결정의 어려움**

| 응답 | 비율 |
|---|---|
| 매우 자주 어렵다 | 17.6% |
| 가끔 어렵다 | 58.8% |
| 거의 어렵지 않다 | 23.5% |
| 전혀 어렵지 않다 | 0% |

**Q4. 어려움을 느끼는 상황** (복수응답)

| 상황 | 응답 수 (비율) |
|---|---|
| 일교차가 큰 환절기 | **14 (82.4%)** |
| 아침과 낮의 온도 차이가 큰 날 | 9 (52.9%) |
| 준비 시간이 부족한 바쁜 아침 | 7 (41.2%) |
| 미세먼지 정보를 모를 때 | 6 (35.3%) |
| 비가 올지 애매한 날 | 4 (23.5%) |
| 아이의 컨디션 변화가 있을 때 | 4 (23.5%) |

→ **상위 2개 응답이 모두 '시간대별 온도 변화'** 관련. 현재 시점 기온만 확인하는 방식으로는 하루 스케줄 접점(등원–야외활동–하원)을 커버할 수 없다는 점이 확인됨. *(→ PRD 회귀 테스트 AC-1 시나리오의 근거)*

**Q5. 날씨·환경 변화로 인한 아이 건강 문제 경험** *

| 응답 | 비율 |
|---|---|
| 자주 있다 (한 시즌 2회 이상) | 23.5% |
| 가끔 있다 | 35.3% |
| 거의 없다 / 없다 | 41.2% |

**Q6. 미세먼지로 인한 야외활동 낭패 경험**

| 응답 | 비율 |
|---|---|
| 자주 있다 (월 2회 이상) | 17.6% |
| 가끔 있다 (월 1회 내외) | 58.8% |
| 거의 없다 | 17.6% |
| 미세먼지를 잘 확인하지 않는다 | 5.9% |

**Q7. 아이 건강·날씨 정보 탐색에 쓰는 하루 평균 시간**

| 응답 | 비율 |
|---|---|
| 1~3분 이내 | **64.7%** |
| 3~10분 | 23.5% |
| 10분 이상 / 거의 안 찾음 | 11.8% |

→ 88.2%가 하루 10분 이내. 정보 탐색에 긴 시간을 쓸 수 없는 구조이므로, **탐색이 아닌 '즉시 실행 가능한 판단 결과'를 제공해야 함.**

## 7. 자유 응답 (Q17, 6건)

- 요즘 부모들이 찾는 장소·의류·유행 질병 정보, 상황별 혼잡도 정보 (예: 비 오는 날 실내 시설 주차 복잡도)
- **조건부 알림**: 맑고 일교차 적은 날은 생략하고, 특이 정보(큰 일교차·미세먼지·한파·폭염)가 있을 때만 알림 (토글 on/off)
- 자녀 나이대별 유행 아이템 정보
- **한 번 정보 입력 후 자동 업데이트**
- 열·병원 진료 등 건강 기록과 습도·기온의 상관관계를 분석해 **아플 만한 시기를 미리 알려주는 기능** (열나요 앱 유사)
- 키즈노트 연동 + 준비물 체크

→ 자유 응답에서 **선제적·조건부 알림, 프로파일 1회 등록 후 지속 반영, 건강 이력 기반 예측**에 대한 수요가 자발적으로 언급됨. Family Memory 및 Agent 로드맵(Phase 2~4) 방향과 부합.

## 8. 시사점 및 제품 반영

1. **포지셔닝 확인** — 부모의 핵심 Job은 정보 확인이 아니라 "오늘 내 아이에게 무엇이 필요한가"에 대한 판단. AiDay는 하루의 첫 육아 의사결정(등원 전 준비 판단)을 지원하는 서비스로서의 가설이 검증됨.
2. **AC-1 회귀 테스트 근거** — 어려움 상황 1·2위가 모두 일교차/시간대별 온도 변화(82.4%, 52.9%). 스케줄 접점별 시계열 판단이 필수 기능임을 뒷받침.
3. **알림 스코프 판단 자료** — 자동 알림이 기능 수요 1·2위(76.5%, 64.7%)이며, 채널은 카카오톡 챗봇 선호(52.9%). v1.0 알림 포함 여부 결정 시 핵심 근거.
4. **신뢰 요건** — 의학 기관 근거 기반 정보가 앱 선택에 영향(70.6%가 4~5점). 안전 레이어·출처 표기 설계의 정당성 확인.
5. **비우선 기능** — 커머스(구매 링크)는 유용성 평가·기능 선호 모두 최하위. 초기 스코프 제외.

## 9. 조사의 한계 (Limitations)

- **표본 크기**: n=17로 통계적 일반화에는 한계. 방향성 검증 목적의 사전 조사로 해석해야 함.
- **표본 구성**: 응답자 중 자녀 없음 4명(23.5%) 포함. 핵심 문항은 자녀 유무와 무관하게 집계됨.
- **조사 형태**: 온라인 설문 기반으로, 심층 맥락 탐색(행동 관찰·후속 질문)은 제한적. 베타 테스트(15~20명) 단계에서 실제 행동 로그로 보완 예정.
- 별표(*) 표기 문항(Q5, Q9)은 원본 차트의 항목–수치 매핑 재확인 권장.
