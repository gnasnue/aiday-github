# Must-have 패키지 — 선제 브리핑 · 지불 도선 (2026-07-28)

> 배경: 심사 리허설에서 "이게 진짜 문제인가 / 기능들이 nice-to-have 아닌가 / 지불 의향이
> 있는가"라는 비판을 받음. 대응은 기능 추가가 아니라 **문서에 이미 있는 답의 실행**이다 —
> 시장선별 v2(2026-07-26)의 결론: "점수를 올리는 방법은 아이디어를 바꾸는 것이 아니라
> 검증을 실행하는 것".

## 근거 (문서 전역 검토 요약)

- **문제의 실재**: 워크어라운드가 증거다 — 전날 확인 41.7% · 여벌옷 상비 33.3% · 워크어라운드 보유 83.3%(맘테스트 n=36). 그런데도 **월내 준비 실패 52.8%**(아이 불편·재준비·긴급 구매). 문제는 "정보 부족"이 아니라 **실패 비용과 그 방지 노동의 1인 집중**.
- **지불이 일어나는 조건** (해외 유일 참조 Huckleberry·Napper): ① 실패 비용이 크고 ② 매일 반복되며 ③ **서비스가 먼저 와서** 결정을 대신한다. 도구(열어야 가치)가 아니라 비서(먼저 옴)에 돈을 낸다.
- **페인 피크**: 환절기 어려움 1위 82.4% → 첫 유료 상품 = 환절기 케어 패스(시장선별 확정: 8주 9,900원·얼리버드 4,900원·첫 주 환불).
