## 2. P0 명세 (검토 반영판)

### P0-1. 마무리 플로우 — `app/review/page.tsx` (BottomNav 밖 풀스크린, 내부 상태머신 2스텝+완료)

**Step 1 — 아침 판단 리뷰 (1/2):**
- 상단 **아침 판단 스냅샷**: 오늘 hook + 준비물 최대 3개 + 생성 시각 (리포트 로컬 캐시 → 없으면 스냅샷 생략하고 일반 문구로 degrade — 게스트·캐시 소실 안전).
- 보조 문구: "정답을 평가하는 것이 아니라, 지우에게 실제로 어땠는지 알려주세요."
- **필수** 전체 적합도 4택: 잘 맞았어요/일부만 맞았어요/잘 맞지 않았어요/실행하지 못했어요 → `overall_fit`.
- **조건부** 옷차림 체감 4택(체크리스트에 의류계 준비물이 있던 날만 — `canonicalPrep` 기반 판정): 더워했어요/적당했어요/추워했어요/잘 모르겠어요 → `thermal_outcome`.

**Step 2 — 아이 하루 리캡 (2/2):**
- **필수** 컨디션 4택: 대체로 편안했어요/조금 불편해했어요/많이 힘들어했어요/잘 모르겠어요 → `day_comfort`.
- 태그 멀티선택(0개 허용, 관찰 어휘만·진단형 금지): 땀 많이/기침·콧물/눈·코 비빔/피부 건조·가려움/평소보다 피곤/옷 갈아입음/야외활동 안 함/특별한 일 없었어요(상호배타). **프로필 `conditions` 기반 정렬**(호흡기 민감 → 기침·콧물 먼저, `lib/domain/child-conditions` 재사용).
- (선택) 한 줄 메모 ≤300자, 자동 키보드 미오픈.

**완료 화면:**
- "오늘의 기록을 저장했어요" + 선택 내용 요약 3줄.
- **Memory Status(3회·0.67 규칙 기반 3단 분기):** 관찰 부족 → "아직은 패턴을 판단하지 않아요 — 몇 번 더 쌓이면 반복되는 경향만 조심스럽게 반영할게요" / 패턴 성립 → "지우의 패턴을 하나 발견했어요 — 기온이 높은 날 더위를 자주 느끼는 편이에요" / 충돌 → "아직 결과가 일정하지 않아요 — 조금 더 지켜본 뒤 반영할게요".
- 기록 스탯: `기록 N일째` + 최근 7일 결과 적합률. CTA `마무리하기` → `/home`.
- **금지 표현:** "학습했어요/체질이 바뀌었어요/완전히 이해했어요" — 관찰 서술("최근 4번의 비슷한 날 중 3번 더워했다는 기록")만.

공통: Draft는 sessionStorage 보존(뒤로가기 안전), 선택 버튼 ≥48px, 색+형태 이중 신호.

- 데모(45~60s): 홈 아침 판단 → `하루 돌아보기` → 적합도 "일부만"+체감 "더워했어요" → 태그 "땀 많이" → 완료 화면 **"패턴을 하나 발견했어요"**(사전 시딩으로 3회째 상태 연출 — 시딩은 실제 저장 포맷 그대로) → 홈 복귀, 카드 "기록 N일째". 클로징: "판단→실행→결과 회수→축적. 이 아이별 결과 라벨은 크롤링으로 얻을 수 없는 자산입니다."
- 데모 시딩 유틸: `?seed=memory` 개발 전용 쿼리로 2일치 기록 주입(프로덕션 노출 금지 — dev/스테이징 한정 가드).

## 5. 향후 계획 (P1 — 이번 범위 제외, ChatGPT 설계를 청사진으로 채택)

1. **서버 영속화:** `daily_reflections`·`daily_action_outcomes` 테이블(제안 스키마·RLS 채택, `child_id`는 children FK로 교정) + `POST /api/daily-reflection`(로그인 필수·오늘/어제만·enum whitelist·중복 upsert). 게스트는 localStorage 유지 후 가입 시 이전(기존 프로필 이전 결정 §3-1과 동형).
2. **아침 체크 상태 영속화:** `daily_action_states` + 저녁 프리필 + 액션별 실행 확인 3택 부활.
3. **리포트 프롬프트 실연동(구 P1-1):** 서버가 user_id+childId로 최근 30일 조회(클라 전달 금지 — 조작 방지) → 결정론 빌더 → 프롬프트 관찰 섹션(관찰 이력·진단 아님·안전 기준 불변 명시) → 캐시 v32 + eval before/after 필수. **안전 우선순위: 안전 규칙 > 당일 환경 > 프로필 > Memory > 표현** (마스크 무근거 추천 금지 v23·v28 유지).
4. **반영 가시화:** `memory.applied` payload + 홈 "최근 기록 반영" 표시 — 근거 칩 계약 개정 절차(DESIGN.md) 필요. 관찰≥3·confidence≥0.67·오늘 환경 관련성 충족 시에만.
5. 노출 게이팅(19:30·리포트 열람·미제출), 어제 기록 오전 10시까지 작성 허용, 기록 수정(24h), me 히스토리, `beta_*` 적합률 뷰(완료율 ≥35% 목표).

## 6. 심사 기준 매핑

- **BM 40:** Family Memory(시장선별 v2 경쟁 방어력 ②)의 실물 착수 + 결과 적합률이라는 판단 품질 정량 지표 + 아이별 결과 라벨 = 이전 불가 데이터 자산. Memory Status의 정직한 3단 판정(패턴/보류/충돌)이 "데이터를 아는 팀" 신호.
- **완결성 40:** 판단→실행→결과 회수→축적→패턴 판정의 루프가 실물로 돔. PRD S-003 계획→구현 일관성. 기존 5화면 무회귀.
