## 발견된 문제 (Findings)

### T1 — `route.ts` try/catch 누락 (P1 · CRITICAL)

**문제:** `client.messages.create()` 호출에 try/catch 없음. Claude API 장애 시 Next.js 런타임 에러가 그대로 노출되어 500 응답 반환.

**수정:**
```typescript
// Before
const message = await client.messages.create({ ... });

// After
try {
  const message = await client.messages.create({ ... });
  const text = message.content[0]?.type === "text" ? message.content[0].text : "";
  return NextResponse.json({ text });
} catch (err) {
  console.error("[AI report] Claude API 오류:", err);
  return NextResponse.json(
    { error: "AI 리포트를 생성하지 못했습니다. 잠시 후 다시 시도해주세요." },
    { status: 503 }
  );
}
```

**적용 커밋:** `8a64a37`

### T2 — `message.content[0].type` optional chaining 누락 (P1 · CRITICAL)

**문제:** `message.content[0].type` 접근 시 content 배열이 비어있으면 런타임 TypeError 발생.

**수정:**
```typescript
// Before
message.content[0].type === "text" ? message.content[0].text : ""

// After
message.content[0]?.type === "text" ? message.content[0].text : ""
```

**적용 커밋:** `8a64a37`

### T3 — AI 실패 시 사용자 피드백 없음 (P2 · HIGH)

// catch 블록

### T4 — 날씨/대기 API 중복 호출 (P2 · HIGH)

**문제:** `fetchEnv` useEffect와 `fetchReport` useEffect 각각에서 `/api/weather`, `/api/air`를 호출. 동일 데이터를 2회 fetch하여 불필요한 공공 API 쿼터 소모.

**원인 분석:**
- `fetchEnv`: 날씨 UI 표시용으로 원본 데이터 fetch
- `fetchReport`: AI 프롬프트 구성용으로 동일 API 재호출

**수정:** `useRef`로 원본 데이터 캐시
```typescript
const weatherRawRef = useRef<object | null>(null);
const airRawRef = useRef<object | null>(null);

// fetchEnv useEffect 내부:
weatherRawRef.current = w;   // 원본 JSON 캐시
airRawRef.current = a;

// fetchReport useEffect 내부:
const w = weatherRawRef.current ?? {};
const a = airRawRef.current as { error?: string; pm10Grade?: number } | null;
// → 별도 fetch 제거
```

**선택 이유:** `useState`로 관리하면 불필요한 리렌더 트리거, `useRef`는 값만 보존하며 리렌더 없음.

**적용 커밋:** `9939991`

### T5 — AI 리포트 localStorage 5분 캐시 미구현 (P3 · DEFERRED)

**문제:** 홈 화면 재진입 또는 새로고침 시 매번 Claude API 호출 발생. 결과가 바뀌지 않는 동일 조건에서도 비용 및 지연 발생.

**제안 구현:**
```typescript
const CACHE_KEY = "aiday:report:cache";
const CACHE_TTL = 5 * 60 * 1000; // 5분

// 저장
localStorage.setItem(CACHE_KEY, JSON.stringify({ text, ts: Date.now(), childId }));

// 읽기
const cached = JSON.parse(localStorage.getItem(CACHE_KEY) ?? "null");
if (cached && Date.now() - cached.ts < CACHE_TTL && cached.childId === childId) {
  setReport(cached.text);
  return;
}
```

**연기 이유:** P1/P2 수정 완료 후 별도 PR로 처리 예정. 캐시 무효화 조건(아이 프로필 변경, 날씨 변화) 정의 필요.
