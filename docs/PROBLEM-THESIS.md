# AiDay Problem Thesis — 왜 이 문제인가

> 이 문서는 아이데이가 어떤 문제를 **사업 문제**로 보고 있는지에 대한 공식 논증이다.
> "이게 해결되면 육아가 해결되냐", "이게 큰 문제냐" 같은 외부 질문에 일관되게 답하기 위한 원천 문서이며,
> [MANIFESTO](../MANIFESTO.md)·[PRD](../PRD.md)·[문제정의 프레임워크 v3](문제정의-프레임워크-v3.md)가 이 문서를 참조한다.

---

## 1. 한 문장 문제정의

**상위 문제:**

> 만 1~8세 자녀를 키우는 맞벌이 가정에서는 아이의 하루가 원활히 운영되도록 **기억하고, 예측하고, 판단하고, 조율하는 책임이 한 사람에게 집중**되어 있다. 각각의 일은 사소해 보이지만 매일 반복되고, 하나가 누락되면 아이의 생활과 부모의 직장 일정이 함께 흔들린다.

**아이데이의 역할:**

> 부모 한 사람이 모든 것을 기억하고 판단하지 않아도 가족의 하루가 굴러가도록 돕는 **육아 일상 운영 에이전트**.

**현재 MVP의 위치:**

> 아이데이는 이 구조적 문제 전체를 한 번에 해결하지 않는다. 가장 빈번하고 매일 반복되며 즉시 검증 가능한 **'아침의 첫 육아 판단'**(환경×아이 체질×오늘 일정 → 옷차림·준비물·케어 방식)에서 시작한다.

---

## 2. 표면 문제와 구조적 문제

온라인 담론에서 가장 흔한 표현은 "시간이 없다"이다. 그러나 시간 부족은 표면이다. 그 아래의 구조는:

- **정보가 부족한 것이 아니라, 여러 정보를 결합해 행동 결론을 내려야 한다.** 날씨 앱·기관 공지·아이 컨디션·경험이 각각 따로 존재하고, 결합은 부모의 머릿속에서 이루어진다. (맘테스트: 판단 시 참고 대상이 날씨 앱 63.9%·컨디션 41.7%·체감 38.9%·공지 27.8%·감 27.8%로 파편화)
- **판단은 매일 반복되며 어제의 결론을 재사용할 수 없다.** 입력값(날씨·일교차·컨디션)이 당일 변수이기 때문이다.
- **판단에 필요한 맥락이 한 사람의 머릿속에만 저장된다.** 체질·일정·과거 반응을 아는 것은 담당자 한 명뿐이다.
- **누락과 실패는 불편을 넘어 죄책감과 직장 리스크로 이어진다.** 돌봄 변수 발생 시 연차 소진·일정 붕괴·퇴사 고민으로 연쇄된다.
- **배우자가 실행을 돕더라도, 무엇을 해야 하는지 정의하고 위임하는 책임은 남는다.** 실행 노동은 나눌 수 있지만 관리·판단 노동은 잘 나눠지지 않는다.

핵심은 시간이 아니라 **최종 운영 책임의 집중**이다: 돌봄에 변수가 생겼을 때, 한 사람이 가족 시스템의 최종 책임자로 남는 구조.

## 3. 왜 사소해 보이는 일이 큰 문제가 되는가

돌봄 운영 부담은 교통사고처럼 한 번의 큰 사건이 아니라 **누적형 문제**다.

- 오늘 뭘 입힐지 → 우산이 필요한지 → 미세먼지는 → 준비물은 → 공지는 읽었는지 → 약은 챙겼는지 → 여벌옷은 → 하원 후 병원은 → 배우자에게 뭘 부탁할지 …
- 각각을 떼어놓으면 사소하다. 그러나 이것이 **매일, 수년간, 직장 업무와 동시에** 수행되면 성격이 달라진다.

외부 평가자는 **개별 과업의 크기**를 보고, 사용자는 **누적된 시스템 부담**을 경험한다. 이 차이가 "이게 큰 문제냐"라는 질문과 실제 사용자 경험 사이의 간극이다.

행동 데이터([맘테스트 n=36](validation/2026-07-문제검증-맘테스트.md))가 보여주는 누적의 실체:

- 아침 환경 확인을 **주 3일 이상 반복: 75.0%**
- 최근 한 달 내 실제 실패·재작업 사건 경험: **52.8%** (아이 불편 호소, 직전 재준비, 여벌옷 기관 전달, 긴급 구매…)
- 문제를 줄이기 위한 자기만의 해결책(전날 확인·여벌옷 상비·역할 분담)을 이미 실행 중: **83.3%**
- 아침 준비 담당: **주 5일 전담 47.2% vs 0일 19.4%** — 가족 안에 운영 담당자 한 명이 존재하는 분포

## 4. 기존 대안이 충분하지 않은 이유

| 대안 | 제공하는 것 | 완료해 주지 않는 것 |
|---|---|---|
| 날씨·환경 앱 | 수치와 시간대별 예보 | 내 아이의 체질·일정과 결합한 행동 결론 |
| 신생아 기록 앱 | 수유·수면 기록 | 유아기 이후의 매일의 Job은 기록이 아니라 판단 |
| 맘카페·커뮤니티 | 타인의 사례 | 내 아이 조건의 판단 (실제로 부모들은 확신이 없어 남의 선택을 물음) |
| 범용 생성형 AI | 질문하면 답변 | 묻기 전의 선제 판단 — 매번 아이 상황을 재설명해야 함 |
| 가족 내 분담 | 실행의 분담 | 기억·예측·판단·조율이라는 관리 노동의 분담 |

공통점: **정보와 기록은 제공하지만, 가족의 맥락을 기억하고 판단을 완료해 주지 않는다.**

## 5. 아이데이가 책임지는 것과 책임지지 않는 것

**지금 해결하는 것 (현재 MVP):**
- 오늘 하루의 첫 육아 판단 — 파편화된 환경 데이터를 아이 체질·일정 맥락으로 결합해, 바로 실행 가능한 결론(옷차림·준비물·케어 방식) 제공
- 판단 시간 단축과 누락 방지

**지금 해결하지 않는 것:**
- 육아 전체, 아이 발달·교육 전체
- 긴급 돌봄 인력 공급, 의료 진단·처방
- 부부 관계, 회사의 돌봄 제도 문제
- 모든 가족 일정·행정 업무

**장기적으로 탐색하되 현재 MVP에 넣지 않는 것 (Post-MVP 가설):**
- 알림장·기관 공지 통합 (맘테스트에서 공지가 이미 판단 입력의 27.8%)
- 공동 양육자 간 판단·준비물 동기화
- 아이 질병 시 대응 플랜
- Family Memory 기반 개인화 심화

## 6. 왜 '아침의 첫 육아 판단'에서 시작하는가

상위 문제의 증상 중 아침 판단을 웨지로 선택한 이유:

1. **가장 빈번하다** — 매일, 모든 가정에서, 등원 여부와 무관하게 발생한다. (외출하지 않는 날에도 실내 케어 판단은 필요)
2. **환경 리스크가 판단을 매일 강제한다** — 미세먼지·꽃가루·자외선·폭염·한파의 일상화와 소아 알레르기 질환 증가로, '오늘의 환경을 내 아이 기준으로 해석하는 일'이 반복 과업이 됐다. 이것이 아이데이가 환경 데이터 해석에서 출발한 배경이다 ([MANIFESTO](../MANIFESTO.md) Core Truth 2층).
3. **즉시 검증 가능하다** — 판단의 품질(아이가 덥거나 춥지 않았는가, 여벌옷이 유용했는가)이 당일 확인된다. 검증 주기가 하루라서 제품 학습 속도가 빠르다.
4. **자발적 수요가 이미 표출되어 있다** — 맘카페 교차 검색에서 '아침준비' 30건+, '오늘 뭐 입히지' 40건+ ([소셜 리스닝](research/2026-07-working-mom-social-listening.md)). 시장 교육이 필요 없는 진입점.
5. **탐색이 아니라 판단의 문제다** — 맘테스트에서 옷차림은 '찾아보는 주제'로는 하위(22.2%)지만 '매일 확인하는 행동'으로는 최상위(75%가 주 3일+). 검색을 도와주는 서비스가 아니라 판단을 완료해 주는 서비스가 필요하다는 뜻이며, 이는 기존 대안들이 비어 있는 지점이다.

확장 논리: 아침 판단에서 신뢰를 얻으면 → 판단에 이미 들어와 있는 인접 입력(공지·준비물·일정)으로 확장 → 공동 양육자 동기화 → 부모 한 사람이 모든 것을 기억하지 않아도 굴러가는 가족 운영 시스템. **각 단계는 앞 단계의 행동 검증을 통과해야 착수한다.**

## 7. 반론과 답변

### "이게 해결되면 육아가 해결되는가?"

아이데이는 육아 전체를 해결한다고 주장하지 않는다. 배달 서비스가 식량 문제 전체를, 송금 서비스가 금융 전체를 해결하지 않는 것과 같다. 제품은 반복적이고 명확한 특정 문제를 이전보다 잘 해결하면 된다. 아이데이가 책임지는 것은 육아 전체가 아니라 **판단 시간, 누락, 실수, 반복 사용이 실제로 개선되는지**다.

### "이게 육아의 궁극적인 목표인가?"

제품과 육아 철학을 혼동한 질문이다. 내비게이션의 목표가 '인간 이동의 궁극적 의미'가 아니라 '덜 헤매게 하는 것'이듯, 아이데이의 직접 목표는 부모의 반복적 운영 부담을 줄이는 것이다. 부모의 스트레스와 실수가 줄면 아이의 안정적인 생활에도 간접적으로 기여하지만, 그것을 직접 약속하지 않는다.

### "이게 큰 문제인가?"

크기를 재는 단위가 다르다. 한 번의 옷차림 판단은 작다. 그러나 문제의 크기는 **모든 예측·기억·판단·조율이 한 사람에게 집중된 채 매일 수년간 누적되는 구조**에서 발생한다. 사업 언어로 번역하면: 부모의 75%가 주 3일 이상 이 판단을 반복하고, 절반이 최근 한 달 안에 실제 실패·재작업을 겪었으며, 83%는 이미 자기만의 해결책에 시간을 쓰고 있다 (자체 맘테스트 n=36). 모집단도 구조적으로 확대 중이다 (막내 6세 이하 맞벌이 53.2%, '15년 대비 +15.1%p).

### "원래 부모가 해야 하는 일 아닌가?"

"원래 사람이 해오던 일"이라는 사실은 시장이 없다는 증거가 아니라, **반복적이고 자동화되지 않은 노동이 존재한다는 증거**다. 세탁·장보기·송금·길찾기도 원래 사람이 직접 했다. 특히 기억·계획·조율 노동은 오랫동안 비용으로 계산되지 않았기 때문에 외부에서 문제로 잘 보이지 않을 뿐이다. 국가데이터처 생활시간조사는 미취학 자녀 가구의 가사노동이 하루 2시간 8분 더 많음을 보여주고, 정부는 돌봄 공백에 대응하는 단기 육아휴직을 2026년 8월 신설했다 — 이미 공적으로 인정된 노동이다.

### "무료 날씨 앱이나 ChatGPT로 되는 것 아닌가?"

날씨 앱은 데이터를 제공하지만 내 아이 기준의 행동 결론을 완료하지 않고, 범용 AI는 매번 아이 정보와 오늘 일정을 재설명해야 한다. 아이데이의 가설은 아이 프로필·생활 일정·결과 피드백을 누적해 **묻기 전에 먼저 판단을 준비하는 것**이다. 단, 이 차이가 반복 사용과 지불로 이어지는지는 검증 중이다 (아래 9절).

### 그럼에도 유효한 질문

멘토 질문의 프레임과 별개로, 다음 질문에는 행동 증거로 답해야 하며 이것이 현재 검증 로드맵이다:

> **이 불편이 실제 반복 사용과 지불로 이어질 만큼 빈번하고 절박한가?**

문제의 실재는 확인됐다 (8절). 반복 사용은 7일 컨시어지 테스트와 베타 지표(아침 재방문율 ≥30% — 북극성)로, 지불 의사는 별도 실험으로 검증한다.

**증거 사용 원칙:** 웨지(아침 판단)의 실재는 1순위 행동 데이터가 담당한다. 상위 문제(운영 책임 집중)는 1순위의 구조 신호 + 2순위 통계 + 3·4순위 질적 신호가 **삼각측량으로 뒷받침하는 구조적 가설**로 유지하며, 소셜 리스닝을 단독 근거로 쓰지 않는다.
