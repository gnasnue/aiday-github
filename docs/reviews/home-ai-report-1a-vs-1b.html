AI 리포트 카드 — 1a vs 1b

두 안 모두 공통 개선(AI hook을 화면 히어로로 승격 · 시간대 카드는 주의만 노출 · 보더 정리)을 담습니다. 다른 건 AI 리포트의 표현 방식과 색입니다. 실제 화면 전체를 나란히 두되, 비교 포인트는 상단 리포트 영역입니다.

1a 정돈 보수적 · 현행 시스템

기존 오렌지 시스템 그대로. hook을 카드 없이 배경 위 히어로로 올리고, 챙길 것은 흰 카드 안 체크리스트. DESIGN.md 수정 불필요.

AI 리포트, 무엇이 다른가

위 두 화면의 상단 리포트 영역만 항목별로 비교합니다.

항목1a 정돈1b 포근
컬러 현행 오렌지(#F5A623) + 웜 뉴트럴. 상태색은 컬러 텍스트+도트. 새 코랄(#E8623C)+세이지(#7DB39C). 결론·완료를 solid 코랄로 채움.
리포트 담는 그릇 카드 없이 배경 위 히어로. hook이 가장 큰 요소(23px/800). 둥근 24px 말풍선형 흰 카드 + 아이 아바타 인사로 시작.
결론(hook) "오늘은 주의가 필요해요" 상태 필 + 생성시각. 한 문장 히어로. "오늘의 결론" 필 + hook 안 핵심어(마스크)를 컬러로.
오늘 챙길 것 체크리스트(체크박스+라인 아이콘+사유), 완료는 취소선. 알약형 태그, 완료(마스크)는 solid 코랄로 채움.
환경 요약 hook 아래 인라인 칩 — 주의만 강조, 나머지는 흐리게. 리포트 밖 4칸 그리드(먼지·꽃가루·자외선·바람), 주의는 틴트.
톤 차분하고 정확 — "정보를 명확하게". 현행 Warm Minimal. 다정하고 부드러움 — 키즈노트·당근 감성. 더 감정적.
구현 비용 낮음 — 컴포넌트 재배치·정리. 시스템 변경 없음. 높음 — 색 토큰 개정 + 앱 전체 재테마 + DESIGN.md 갱신.

1a 이럴 때

현재 Warm Minimal 정체성을 지키면서 홈의 정보 위계만 끌어올리고 싶을 때. 빠르게 안전하게 개선하고, 색 실험은 나중에.

1b 이럴 때

이번 기회에 앱의 감성 아이덴티티를 다정한 코랄+세이지로 리브랜딩하고 싶을 때. 홈만이 아니라 전 화면 재테마를 감수.

두 안의 데이터·문구·아이콘은 실제 코드(recommendation-engine · weather-mock · LineIcon)에서 가져온 것이라, 어느 쪽이든 그대로 구현으로 옮길 수 있습니다. Turn 2(이미지 저장·공유 CTA)는 이번 비교에서 제외했습니다.
