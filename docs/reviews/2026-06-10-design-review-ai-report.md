## 발견된 문제 (Findings)

### FINDING-001 — BottomNav 이모지 아이콘 (P1 · HIGH)

**위치:** `components/BottomNav.tsx`

**문제:**
```typescript
// Before — OS 의존적 이모지
{ icon: "🏠", label: "홈", to: "/home" },
{ icon: "💨", label: "환경정보", to: "/env" },
{ icon: "👕", label: "옷차림", to: "/outfit" },
{ icon: "💚", label: "건강팁", to: "/tips" },
{ icon: "👤", label: "마이", to: "/me" },
```

Android/iOS/Windows 환경별 이모지 렌더링이 달라 시각적 일관성 깨짐. DESIGN.md Known Issue #3에 명시된 문제.

**수정:**
```typescript
// After — Lucide React
import { Home, Wind, Shirt, Heart, User } from "lucide-react";

{ icon: Home,  label: "홈",     to: "/home" },
{ icon: Wind,  label: "환경정보", to: "/env" },
{ icon: Shirt, label: "옷차림",  to: "/outfit" },
{ icon: Heart, label: "건강팁",  to: "/tips" },
{ icon: User,  label: "마이",    to: "/me" },

// 렌더:
<n.icon size={22} strokeWidth={1.75} />
```

**적용 커밋:** `6d3c8c4`

### FINDING-002 — 랜딩 헤더 nav 버튼 터치 타겟 미달 (P1 · HIGH)

**위치:** `app/page.tsx` — 헤더 로그인/무료시작 버튼

**문제:**
```tsx
// Before — h-8 = 32px (DESIGN.md 최소 44px 미달)
<Button variant="ghost" size="sm" className="h-8 px-3 text-xs">로그인</Button>
<Button size="sm" className="h-8 bg-primary px-4 text-xs">무료 시작</Button>
```

모바일 기기에서 작은 터치 타겟은 조작 실수를 유발하며, WCAG 2.5.5 권고 기준(44×44px) 미달.

**수정:**
```tsx
// After — h-11 = 44px
<Button variant="ghost" size="sm" className="h-11 px-3 text-xs text-foreground">로그인</Button>
<Button size="sm" className="h-11 bg-primary px-4 text-xs text-primary-foreground ...">무료 시작</Button>
```

**적용 커밋:** `dcd7839`

### FINDING-003 — 랜딩 페이지 이모지 사용 (P2 · MEDIUM)

**위치:** `app/page.tsx` — pain points 카드, differentiators 카드

**문제:**

_Pain points_ 카드:
```typescript
// Before — 감정 이모지 (OS 의존)
{ emoji: "😵‍💫", text: "날씨 앱, 미세먼지 앱…" },
{ emoji: "🤔", text: "일교차가 심한 날…" },
```

_Differentiators_ 카드:
```typescript
// Before — 기능적 이모지
{ emoji: "🔄", title: "복잡한 수치를 육아 언어로", ... },
{ emoji: "👶", title: "우리 아이 맞춤 해석", ... },
```

**수정 전략:**

- **Pain points**: 감정 이모지(😵‍💫🤔🤯🤒)는 Lucide 직접 대체가 어색함 → 이모지 제거 후 오렌지 액센트 라인으로 대체
```tsx
<div className="w-1 self-stretch rounded-full bg-primary flex-shrink-0" />
```

- **Differentiators**: 기능적 이모지(🔄👶⏰📲)는 Lucide 대응 아이콘 존재 → 직접 교체
```typescript
import { RefreshCw, Baby, Clock, Smartphone } from "lucide-react";

{ icon: RefreshCw,  title: "복잡한 수치를 육아 언어로", ... },
{ icon: Baby,       title: "우리 아이 맞춤 해석", ... },
{ icon: Clock,      title: "시간대별 준비 가이드", ... },
{ icon: Smartphone, title: "미리 받아보는 육아 가이드", ... },

// 렌더:
<d.icon size={20} strokeWidth={1.75} className="text-accent" />
```

**적용 커밋:** `b59022e`
