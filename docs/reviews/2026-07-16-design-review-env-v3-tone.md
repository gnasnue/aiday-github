# 환경정보(/env) 톤 정렬 리뷰

## 첫인상 진단

env만 v2의 잔재(크림 표면·틴트 카드·브랜드 오렌지 남발)가 남아 "다른 앱의 화면"처럼 읽혔다.
다른 4개 탭은 웜 그레이 배경 + 순백 카드 + 상태색 텍스트로 통일된 상태.
톤 불일치의 실체는 세 가지: **① 크림(secondary) 면 3곳, ② 상태 표현에 브랜드 오렌지(accent), ③ 타일마다 다른 틴트 배경+보더 문법.**

## Findings & Fixes (verified — 커밋 1건, before/after 실기 확인)

| # | Impact | Finding | Fix |
|---|--------|---------|-----|
| F1 | High | 인사이트 카드가 tone별 틴트 배경+보더(`border-accent/30 bg-accent/5` 등) — v3 보더 금지 위반, 같은 리스트에서 카드 문법 불일치 | 전부 `bg-card shadow-soft` 순백 통일, 상태는 아이콘 컨테이너가 전담 |
| F2 | High | "오늘의 야외활동 지수"가 대형 크림(secondary) 카드 — 페이지 최대 이질감 | 화이트 L2 히어로(`bg-card shadow-card`)로 승격 |
| F3 | High | 대기질·꽃가루·자외선 타일 `levelBg` 함수가 등급별 틴트 배경+보더 부여, "높음/나쁨"에 브랜드 오렌지 텍스트 | `levelBg` 삭제 → `bg-card shadow-soft` 통일, `levelTone`을 status-bad/warn/neutral 시멘틱으로 교정 |
| F4 | Medium | 자외선(회색 면) vs 온·습도(화이트) 쌍 표면 불일치, "다습"이 brand accent | 표면 통일, 다습/건조 → status-warn, 쾌적 → status-neutral |
| F5 | Medium | 주간 날씨: 주말 행 크림 하이라이트 + 토·일 모두 오렌지, 온도 바 `bg-primary/70`, 강수 강조 오렌지, 날씨 아이콘 오렌지 | 하이라이트 제거, 요일 달력 관례(토=status-info·일=status-bad), 온도 바 뉴트럴(`bg-foreground/30`), 강수 ≥50% → status-info, 아이콘 뉴트럴 |
| F6 | Polish | 현재 날씨 내부 지표 패널 `bg-background/70` (배경색 재사용) | `bg-muted/60` 시스템 토큰으로 |
| F7 | Polish | "기상청 출처" 링크가 underline+muted — v3 링크 문법 아님 | `text-accent font-medium` |
| F8 | Polish | 꽃가루 나무 아이콘 오렌지(accent) — 장식에 브랜드색 | muted-foreground |
| F9 | Polish | 10~11px 마이크로 텍스트 5곳 (v3: 11px 미만 금지, 11px은 eyebrow 전용) | 12px(text-xs) 수렴 |

**유지한 것:** "현재 날씨" 대형 태양 아이콘과 카드 라벨의 오렌지 — 카드당 1개의 브랜드 포인트는 v3 허용 범위(히어로 포인트).
