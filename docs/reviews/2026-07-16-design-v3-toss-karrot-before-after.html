5. 무엇을 어디서 가져왔나

벤치마크가져온 원칙AiDay 적용
토스 — 정보 신뢰"한 화면에 유저가 할 단 하나의 액션"이 선명할 것. 그레이 배경 + 순백 카드의 면 분리, 보더 최소화, 타이포가 위계를 전담홈 = AI 결론 1개가 히어로. 배경 채도 다운 + 보더 카드 폐지. display 26/800 vs caption 13 대비
당근 — 오렌지의 온기오렌지는 화이트 위에서 포인트로 쓸 때 가장 따뜻함. 리스트 행 + chevron 문법. 휴머니스트 톤의 마이크로카피solid 앰버 남발 → 틴트+딥 텍스트 조합. 마이·설정을 리스트 행으로. 브랜드 오렌지 #F97316로 반 단계 심화
두 앱 공통이모지를 UI 아이콘으로 쓰지 않음. 아이콘은 단일 세트·단일 스트로크이모지 71건(10개 파일) → Lucide 1.75 스트로크로 전면 교체

유지(SAFE): 오렌지 브랜드 · Pretendard · 390px 프레임 · 화면 구조 · 상태 3단계 색 · 웜 뉴트럴 hue.
리스크(확연한 차이를 만드는 곳): ① 배경 베이지 → 웜 그레이(온기 소폭 감소, 전문성 대폭 상승) ② 카드 보더 폐지(문법 전면 개정) ③ 브랜드 오렌지 심화 #F5A623 → #F97316(기존 앰버 아이덴티티와 결별).
