· 글로벌 스텝퍼 제거 — Family Memory는 특성별 병렬 상태(더위=반영 / 추위=정보 적음)라 전역 단계 하나는 거짓 단순화이고, 마지막 단계 도달 시 "완료된 제품"처럼 보인다. 대체 = 특성별 반응 지도: 가장 중요한 반응 1개 큰 카드 + 2열 타일 + 모두 보기. 상태 시각 언어: 프로필(muted) / 알아보는 중(점선) / 확인·반영(피치 tint + 배지). 아이콘은 Lucide(이모지 금지).
· "확인 중 n/3" 노출 제거 — 퀘스트화는 편향 응답 유도 + 데이터 수집 인상. 외부는 자연어("비슷한 결과가 몇 번 있었어요 · 조금 더 알아보는 중"), 내부 판정(3회·0.67)은 유지.
· 오늘 결과를 Hero에 통합 — 입력 직후 사용자가 가장 먼저 확인하고 싶은 것은 "방금 알려준 게 반영됐는가". Hero = 오늘 결과 헤드라인("더운 날 반응이 조금 더 또렷해졌어요") + 오늘 알려준 내용 칩 + 크림 다음 판단 + 수정.
· G 저장 보상 = 특성 승격의 순간 — 숫자 +1이 아니라 점선 카드(알아보는 중)가 tint(반영)로 뒤집히는 변화 + NEW(24시간 후 제거) + 내일 미리보기.
· D 미입력: 질문형 Hero("오늘 지우에게 실제로 어땠나요?") + 아침 안내 인용 + CTA를 안 눌러도 반응 지도가 가치를 준다. E 첫 진입: "0에서 시작"이 아니라 "이미 이만큼 알고 있어요"(프로필 칩) — 링·스텝퍼·숫자 전부 없음.
· 어휘: 기록/트래킹/N일째/관찰 수/n/3/경향 1개 사용자 노출 금지. "관리"는 설정(톱니) 메뉴 안으로 — 메뉴 구성: AiDay가 참고하는 정보 / 오늘 결과 수정 / 과거 결과 보기 / 전체 삭제.
