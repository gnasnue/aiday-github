# 홈 화면 비주얼 리스타일 디자인 리뷰

## 검토 기준

- 390px 고정 모바일 프레임과 20px 가로 여백
- Warm Minimal: 색·그림자로 깊이를 만들며, 일러스트는 금지
- 예외: `CharacterReport`의 아이 캐릭터 일러스트만 허용
- 모든 인터랙티브 요소 44×44px 이상
- Lucide React 아이콘, OS 이모지 미사용

## 발견 사항

### D1 — P1: 추천 아이템 SVG가 일러스트 금지 규칙의 예외를 확장함

`ItemIllustration.tsx`는 목수건·마스크·로션·가디건의 고정 SVG 일러스트를 추가한다. DESIGN.md는 신체 부위 기반 설명을 위해 `CharacterReport`의 아이 캐릭터만 유일한 예외로 허용한다. 하드코딩 카드를 유지한다는 제품 결정은 카드의 데이터 상태에 대한 결정이며, 새로운 일러스트 예외 승인으로 해석할 수는 없다.

필수 선택:

1. 상품 카드는 유지하되 Lucide 기반의 단순 아이콘 또는 텍스트 표현으로 바꾼다.
2. SVG 일러스트를 유지하려면 디자인 시스템의 예외·사용 범위·색상 토큰을 사용자 승인 후 DESIGN.md에 기록한다.

### D2 — P1: 체크리스트 행의 최소 터치 영역이 44px에 못 미침

체크박스가 20px이고 버튼의 세로 패딩이 각각 10px이므로, 한 줄 항목의 높이는 약 40px이다. 최소 44px 기준에 4px 부족하다.

Before:

```tsx
<button className="flex w-full items-center gap-3 px-1 py-2.5 text-left">
```

After:

```tsx
<button className="flex min-h-11 w-full items-center gap-3 px-1 py-2.5 text-left">
```

### D3 — P2: 신규 커스텀 라인 아이콘은 Lucide React 단일 라이브러리 원칙과 불일치

`LineIcon.tsx`는 자체 SVG path 세트를 도입한다. 아이콘의 획·비율·추가 상태를 별도로 유지해야 하므로 화면 전체의 Lucide 일관성과 유지 비용을 모두 악화시킨다. 먼저 Lucide 대체 아이콘을 사용하고, 불가피한 전문 아이콘만 D1의 명시적 예외에 포함한다.

### D4 — P2: 추천 아이템 SVG가 디자인 토큰 밖의 고정 HEX 팔레트를 사용

`ItemIllustration.tsx`의 채움과 선 색이 컴포넌트에 고정되어 있어 라이트/다크 모드와 디자인 토큰의 색상 체계에 연동되지 않는다. D1에서 예외를 승인한다면 `currentColor` 또는 CSS 변수 기반 토큰으로 전환해야 한다.

## 결론

상태 칩의 흰 배경·도트·텍스트 계층, 아바타의 이모지 대체, 390px 카드 레이아웃은 Warm Minimal 방향과 맞는다. 다만 D1·D2(P1)를 해소하거나 명시적으로 승인하기 전에는 이 비주얼 변경을 완료로 볼 수 없다.
