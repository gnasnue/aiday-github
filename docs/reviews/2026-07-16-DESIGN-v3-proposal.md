# AiDay 디자인 시스템 v3 제안 — "White Report"

## 진단 요약 (왜 "전문성이 떨어져 보이는가")

베타 평가에서 낮은 점수를 받은 원인은 장식 부족이 아니라 **문법 불일치**다.

1. **이모지가 UI 아이콘** — 71건 / 10개 파일 (tips 카드, me 아바타·계정 메뉴, outfit 아이템, home 추천템, env 태양, onboarding). 토스·당근 어느 쪽도 UI 아이콘에 raw 이모지를 쓰지 않는다. OS별 렌더링이 달라 "웹뷰 프로토타입" 인상을 만드는 1순위 요인.
2. **베이지 위 베이지** — 웜 페이퍼 배경(#FCFAF8) + 크림 카드(secondary/soft) + 웜 보더가 겹쳐 표면 위계가 뭉개진다. 토스는 그레이 배경 + 순백 카드의 면 분리로 신뢰감을 만든다.
3. **전부-카드 레이아웃** — 모든 정보가 보더 있는 카드. 설정·프로필류는 당근식 리스트 행이 표준.
4. **타이포 위계 평탄** — 섹션 제목이 모두 같은 크기·간격(22px/mt-8), 스케일 밖 9~11px 남발 (2026-07-15 리뷰 P1과 동일 진단).
5. **오렌지 역할 혼재** — 브랜드·경고·링크·진행이 모두 오렌지 계열 (2026-07-15 리뷰 P2).

## SAFE (유지) / RISK (변경)

**SAFE:** 오렌지 브랜드, Pretendard, 390px 프레임, 화면 구조(홈 히어로→체크리스트→타임라인→케어플랜), 상태 3단계 색(good/warn/bad), 웜 뉴트럴 hue(24~36) 원칙, minimal-functional 모션.

**RISK (before/after 차이를 만드는 곳):**
1. **배경 베이지 → 웜 그레이** (`36 45% 98%` → `30 15% 96%`) — 온기 소폭 감소, 전문성 대폭 상승. 오렌지·크림 포인트가 오히려 살아남.
2. **카드 보더 폐지 → 면 분리** — 카드 문법 전면 개정 (`border border-border/60 shadow-soft` → 보더 없음 + 초경량 섀도). 2026-07-13 표준의 개정.
3. **브랜드 오렌지 심화** `#F5A623` → `#F97316` — 기존 앰버(병아리 노랑끼) 아이덴티티와 결별, 당근 톤에 근접. CTA 흰 텍스트 가능(17px bold 이상). 소형 텍스트는 brand-deep 사용으로 WCAG 유지.

### 신규 컴포넌트 문법

- **리스트 행 (당근 패턴):** 높이 56px, `아이콘 컨테이너(36px, rounded-xl, muted 또는 brand-tint) + 16px/500 레이블 + chevron`. 행 사이 divider. 마이·설정·출처·카테고리 목록에 카드 대신 사용.
- **CTA 버튼 (토스 패턴):** 52px, rounded-[14px], primary solid + 흰 17px/700. secondary는 muted 배경.
- **칩:** 활성 = brand-tint 배경 + brand-deep 텍스트 (solid 앰버 칩 폐지). 상태 칩은 기존 유지(흰 배경+상태색 텍스트+도트).
