# 전 화면 디자인 일관성 + UI/UX 감사

## 한 줄 진단

색·카드 문법·타이포 스케일은 지난 v3 작업(0.3.5.0~0.3.6.1)으로 **이미 잘 통일**돼 있다. 지금 "톤이 안 맞는" 실체는 시각 토큰이 아니라 **화면 골격(상단바·페이지 타이틀) 문법의 분열**이다. 5개 탭이 공용 헤더 없이 각자 인라인 `<header>`를 들고 있어 규칙이 셋으로 갈렸다.

## 실측 (상단바 / 최상위 제목)

| 화면 | 상단바 좌 | 상단바 우 | 페이지 타이틀 |
|------|----------|----------|--------------|
| home | 로고 | 알림·설정 | 없음(프로필 칩→히어로) |
| me | 로고 | 알림·설정 | h1 20/700 "마이페이지" +서브 |
| env | **뒤로가기** | 새로고침 | **h1 없음** · h2 20/700 |
| outfit | **뒤로가기** | 없음 | 영문 eyebrow+h1 20/700 |
| tips | **뒤로가기** | "근거 기반" 배지 | h1 20/700 "건강팁" +서브 |

타이포 스케일 자체(히어로 26/800, 페이지 20/700, 섹션 17/700)는 전 화면 일치 — 양호.

## Findings

### F1 — 상단바 문법이 3종으로 분열 (High)
5개 모두 BottomNav의 동등한 목적지인데 **env·outfit·tips는 뒤로가기 화살표(`router.back()`)**, home·me는 알림+설정. 우측 액션도 새로고침/배지/없음/알림·설정으로 제각각. 토스·당근의 최상위 탭은 뒤로가기를 절대 노출하지 않는다(부모 화면이 없으므로 눌러도 의미 없음). 사용자가 탭을 옮길 때마다 골격이 바뀌어 "다른 앱"처럼 느껴지는 1차 원인.
- 근거: `home/page.tsx:997`, `env/page.tsx:315`, `outfit/page.tsx:412`, `tips/page.tsx:268`, `me/page.tsx:191` — 헤더가 5곳에 각자 인라인.
- 개선: 공용 `PageHeader` 컴포넌트로 통일. 탭에서는 뒤로가기 제거, 좌=로고(또는 페이지명), 우=그 화면의 의미 있는 단일 액션.

### F2 — 페이지 타이틀 패턴 불일치 (Medium)
타이틀 유무·형식이 화면마다 다름: home=없음 / env=h2가 타이틀 / outfit=영문 eyebrow+h1 / tips·me=h1+서브. 진입 시 "여기가 어디인지"를 잡아주는 방식이 일관되지 않음.
- 개선: 탭별 페이지 타이틀 규칙 하나로. (예: 좌측 로고 유지 화면은 첫 섹션이 타이틀 역할, 그 외는 h1 20/700 + 선택적 서브 1줄)

### F3 — env에 h1 부재 (Medium, 접근성)
env는 `<h1>`이 없고 20px `<h2>`가 최상위. 나머지 화면은 h1 존재. 스크린리더 문서 구조·SEO·일관성 모두에서 어긋남.
- 개선: env 최상위 제목을 h1로 승격(시각 스타일은 유지).

### F4 — outfit 영문 라벨 (Polish)
`TODAY'S OOTD` eyebrow, `INNER·BOTTOM·ACC` 카테고리 영문. 한국어 앱에서 outfit만 영문 라벨을 씀 — 톤 이질. env·tips·me엔 없음.
- 개선: 한국어(또는 한국어 주 + 영문 보조)로 통일하거나 제거.

## 관찰 (이번 스코프 제외 — 별도 작업 예정)
- **날씨 정보 3중 노출**: home(시간대별 환경+케어플랜 온도) · env(현재 날씨+주간) · outfit(상단 날씨 카드). 사용자가 outfit 카드를 홈으로 옮기는 방향을 별도로 검토 중. 이번 감사에선 구조 변경 안 함.
