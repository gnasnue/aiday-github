# Home 화면 UI/UX 디자인 리뷰 — Premium SaaS / AI Service 기준

## 한 줄 진단

현재 홈은 **웜 뉴트럴 색상, 일관된 라운드, 실제 데이터 기반 AI 리포트**까지는 잘 갖춰져 있다. 다만 프리미엄 AI 서비스의 핵심인 “첫 3초 안에 결론 → 바로 할 일 → 필요할 때 근거 확인” 흐름보다, 여러 섹션이 같은 강도로 길게 이어지는 정보 피드에 가깝다. 더 장식하기보다 **홈의 역할을 한 번의 판단과 실행으로 좁히고, 미완성 인터랙션과 중복 정보를 걷어내는 것**이 먼저다.

검토는 390px 고정 프레임의 현재 코드와 `DESIGN.md`, `SPEC.md`, `docs/PRODUCT-DECISIONS.md`를 대조했다. `http://localhost:3000/home`의 HTTP 200 응답은 확인했으나 인앱 화면 제어 연결 오류로 이번 감사에서는 스크린샷을 확보하지 못했다.

## 우선순위 Findings

### P1 — 홈의 핵심 판단이 중복 섹션에 희석된다

- 근거: AI 리포트 안에 이미 `오늘 챙길 것`이 있고(`app/(main)/home/page.tsx:883`), 바로 아래 `시간대별 환경`은 다시 준비물 키워드를 노출하며(`:1002`), `하루 케어 플랜`도 같은 시간대와 준비물을 다시 보여준다(`:1024`). 마지막에는 상품 추천까지 이어진다(`:1100`).
- 문제: 사용자는 “그래서 지금 무엇을 하면 되는가”보다 같은 결론을 다른 형식으로 여러 번 읽게 된다. 긴 스크롤과 반복은 정보량은 많아 보이지만 AI가 정리해 준다는 가치와 반대다.
- 개선: 홈을 `오늘의 한 줄 판단 → 바로 체크할 준비물 → 변화가 있는 시간대 1~2개 → 상세 화면 링크` 순서로 압축한다. 전체 환경표는 `/env`, 전체 케어 타임라인은 필요 시 펼침 또는 별도 상세로 보낸다.

### P1 — 동작하지 않는 기능이 완성된 affordance로 노출된다

- 근거: 알림에 항상 강조 도트가 있으나 클릭하면 “새 알림이 없어요” 토스트만 나온다(`:709-715`). 설정(`:717-722`), 위치 변경(`:758-765`), 저장·공유(`:803-815`)도 준비 중 토스트다. 상품 카드는 “외부 구매 페이지로 이동합니다”라고 알리지만 실제 이동하지 않는다(`:1111-1114`).
- 문제: 프리미엄 인상은 시각적 화려함보다 예측 가능성에서 생긴다. 눌러도 아무 일도 일어나지 않는 컨트롤은 베타·데모 인상을 강하게 만든다. 특히 알림 도트는 거짓 긴급 신호다.
- 개선: 실제 동작 전에는 숨기거나 disabled 상태와 “준비 중” 레이블을 명시한다. 알림 도트는 실제 unread 상태에서만 표시하고, 상품 카드는 실연동 전 전체 섹션을 숨긴다. 이는 `PRODUCT-DECISIONS.md:44`의 공개 베타 차단 기준과도 일치한다.

### P1 — 리포트 헤더가 도구 모음 때문에 과밀하다

- 근거: 350px 콘텐츠 폭 안에서 `AI 리포트`, 생성 메타, 새로고침, 저장, 공유가 한 줄을 경쟁한다(`:788-817`). 생성 메타에는 `truncate`가 적용된다.
- 문제: 히어로의 첫 시선이 결론이 아니라 작은 레이블과 아이콘 3개로 분산된다. 메타데이터가 잘려 보이면 신뢰 정보도 불완전해진다.
- 개선: 첫 줄은 `AI 리포트 + 생성 시각`만 유지한다. 새로고침은 텍스트가 있는 단일 보조 액션으로 두고, 저장·공유는 실제 구현 뒤 overflow 메뉴로 이동한다. 결론 문장을 카드 상단의 가장 강한 시선점으로 만든다.

### P1 — 타이포 스케일 밖의 초소형 텍스트가 가독성과 고급감을 떨어뜨린다

- 근거: `DESIGN.md`의 최소 단계는 xs 12px이다. 현재 시간대 카드 11px(`:964`, `:970`, `:974`), 준비물 칩 10px(`:1010`), 추천 근거 9px(`:1119`), 상품명 13px(`:1123`)이 사용된다.
- 문제: 작은 화면에 더 많은 정보를 넣기 위한 축소로 보이며, 부모가 아침에 빠르게 훑는 맥락과 맞지 않는다. 프리미엄 서비스의 조밀함은 작은 글씨가 아니라 정보 삭제와 정렬로 만든다.
- 개선: 본문 16px, 보조 14px, 캡션·태그 12px의 기존 스케일로 수렴한다. 12px로 올렸을 때 공간이 부족한 정보는 우선순위가 낮다는 신호로 보고 제거하거나 상세로 이동한다.

### P1 — 추천 아이템이 AI 육아 판단보다 커머스 인상을 남긴다

- 근거: 추천 상품은 고정 가격과 일러스트를 가진 가로 카드로 노출된다(`:1100-1125`). 실제 구매 이동은 없다. `PRODUCT-DECISIONS.md:44`는 실연동 전 숨김을 출시 기준으로 정한다.
- 문제: 사용자는 데이터의 정확성보다 수익화 의도를 먼저 의심할 수 있다. 미완성 가격과 이동은 홈 전체의 데이터 신뢰까지 낮춘다.
- 개선: 현 단계에서는 섹션을 숨긴다. 향후 재도입 시 “오늘 준비물”과 중복되지 않는 경우에만, 가격보다 추천 근거·보유 여부·대체 가능성을 먼저 보여준다.

### P2 — 섹션 제목과 간격이 모두 같아 페이지가 쿠키커터처럼 보인다

- 근거: `시간대별 환경`, `하루 케어 플랜`, `추천 아이템`이 모두 22px bold, `mt-8`로 시작한다(`:949-950`, `:1025-1026`, `:1101-1104`).
- 문제: 사용자가 어느 섹션이 핵심이고 어느 섹션이 참고인지 구분하기 어렵다. 반복되는 동일 템플릿은 완성도는 있어도 에디토리얼한 판단이 없는 화면처럼 보인다.
- 개선: AI 결론만 hero, 실행 목록은 18px 카드 타이틀, 참고 정보는 12px eyebrow + 18px 타이틀 또는 링크 행으로 낮춘다. 섹션 간격도 중요도에 따라 24/32/48px로 의도적으로 구분한다.

### P2 — 브랜드 오렌지와 경고 오렌지의 역할이 가까워 의미가 흐려진다

- 근거: `text-accent`가 AI 레이블(`:789`), 본문 강조(`:146`), 진행 수치(`:891`), 체크리스트 아이콘(`:917`)에 쓰이고 별도로 `status-warn`도 오렌지 계열이다.
- 문제: 사용자가 “브랜드 강조”, “눌러야 하는 것”, “주의해야 하는 것”을 색만으로 즉시 구분하기 어렵다. 오렌지가 많아질수록 브랜드 포인트의 희소성도 사라진다.
- 개선: primary는 활성 선택과 실제 CTA에만, status-warn은 위험·주의에만 쓴다. AI 본문의 일반 강조는 foreground 굵기만 사용하고, trust/meta는 neutral로 유지한다.

### P2 — 카드 elevation 문법이 표준과 어긋나고 레이어 목적이 불명확하다

- 근거: 디자인 표준은 `rounded-2xl border border-border/60 bg-card p-5 shadow-soft`이다(`DESIGN.md:142`). 히어로는 `rounded-[18px]`(`:786`), 시간대 카드는 shadow 없이 hover 때만 shadow(`:959`), 케어 플랜은 border 없는 muted/secondary 면(`:1056`), 상품 카드는 다시 border+hover shadow(`:1114`)다.
- 문제: 어떤 요소가 떠 있고, 선택 가능하며, 단순한 그룹인지 시각 언어만으로 예측하기 어렵다. 모바일에서 hover 중심 변화는 실질적인 피드백도 아니다.
- 개선: 세 단계로 단순화한다. `Level 0` 페이지 배경, `Level 1` 정보 그룹(soft/muted, shadow 없음), `Level 2` 핵심 AI 카드(card+border+soft shadow). 그림자는 핵심 카드 한 곳에만 유지하고 눌리는 요소는 active 상태를 설계한다.

### P2 — 4px spacing 시스템을 벗어난 임의값이 많다

- 근거: 프로필 `py-[5px]`, 리포트 칩 `px-[11px] py-[5px]`, 텍스트 `14.5px`, 도트 `5px`, 추천 근거 `9px` 등이 반복된다(`:735`, `:867`, `:922`, `:991`, `:1119`).
- 문제: 개별 컴포넌트는 맞아 보여도 전체 화면에서 baseline과 밀도가 미묘하게 흔들린다. 시스템이 아니라 픽셀 보정의 누적으로 느껴진다.
- 개선: 여백은 4/8/12/16/24/32px, 타입은 정의된 12/14/16/18/22/28px로 통합한다. 예외는 아이콘 광학 보정처럼 불가피한 경우만 문서화한다.

### P2 — AI의 신뢰 근거가 가장 작은 보조 문구로 밀려 있다

- 근거: 프로필 기준·기상청·에어코리아 출처가 11px, `muted-foreground/70`으로 카드 최하단에 표시된다(`:941-944`).
- 문제: 아동 건강·환경 판단 서비스에서 데이터 출처와 갱신 시각은 장식적 캡션이 아니라 구매 이유에 가까운 핵심 신뢰 정보다.
- 개선: 생성 시각과 출처를 하나의 `데이터 기준` 행으로 통합해 최소 12px, 충분한 대비로 표시한다. 필요하면 “왜 이렇게 판단했나요?”를 펼쳐 개인화 조건과 환경 임계값을 설명한다.

### P2 — 리포트 도구 버튼의 터치 타겟이 44px보다 작다

- 근거: 18px 아이콘에 `p-2.5`가 적용돼 실질 크기가 약 38px다(`:795-815`). `DESIGN.md` 최소 기준은 44×44px이다.
- 문제: 한 손 조작에서 오탭 위험이 있고, 아이콘 3개가 가까워 문제를 키운다.
- 개선: 최소 `h-11 w-11`을 보장한다. 다만 P1에서 제안한 대로 도구 수 자체를 먼저 줄이는 편이 낫다.

### P3 — 상단 컨텍스트가 결론 이전의 세로 공간을 많이 차지한다

- 근거: sticky header 56px 뒤에 프로필 탭 44px, 위치 행 44px와 각각의 여백이 이어지고 AI 카드가 시작된다(`:705-769`).
- 문제: 첫 화면에서 실제 가치인 AI 결론이 아래로 밀린다. 프로필과 위치는 중요한 컨텍스트지만 매 방문마다 같은 강도로 읽을 필요는 없다.
- 개선: 프로필 이름·나이와 위치를 한 개의 44px context switcher로 합치거나, 위치를 리포트 메타에 넣어 첫 viewport에 결론과 준비물 첫 항목이 함께 보이게 한다.

## 권장 목표 구조

1. **Context bar** — 아이 선택 + 위치/데이터 갱신 시각을 한 줄로 압축
2. **AI decision hero** — 오늘의 한 줄 결론, 이유 1~2줄, 주의 상태 최대 2개
3. **Primary action** — 오늘 챙길 것 3~4개, 체크 진행 상태
4. **Only if changed** — 비·미세먼지·기온 급변이 있는 시간대만 1~2개 노출
5. **Secondary navigation** — `시간대별 환경 전체 보기`, `오늘 케어 플랜 보기`
6. **홈에서 제거** — 미동작 저장/공유/설정, 가짜 알림 도트, 실연동 전 상품 추천

이 구조의 목적은 콘텐츠를 덜 보여주는 것이 아니라, AI가 이미 정리한 결과를 사용자가 다시 정리하지 않게 만드는 것이다.

## 개선 순서

1. 미동작 affordance와 추천 아이템 제거
2. AI 리포트 헤더 단순화 + 신뢰 정보 승격
3. 시간대별 환경과 케어 플랜의 중복 제거 및 상세 이동
4. 타이포·spacing·touch target을 디자인 토큰으로 정규화
5. 마지막에만 elevation과 active/pressed 상태를 미세 조정

## 유지할 강점

- 390px 프레임과 20px 좌우 여백은 일관적이다.
- 웜 뉴트럴 배경, 카드, border 색이 브랜드 오렌지와 자연스럽게 연결된다.
- AI hook을 22px 굵은 제목으로 둔 판단은 홈의 핵심 가치와 맞는다.
- 환경 상태를 good/neutral/warn으로 단순화한 방향은 빠른 스캔에 유리하다.
- 체크리스트를 리포트 안의 실제 행동으로 연결한 점은 단순 정보 앱보다 제품 가치가 높다.

## 결론

현재 화면은 “정돈된 기능 많은 육아 대시보드” 수준에는 도달했지만, “AI가 나 대신 오늘의 판단을 끝내 주는 프리미엄 서비스”로는 한 단계 부족하다. 우선순위는 그림자나 그라데이션 추가가 아니라 **중복 제거, 가짜 기능 제거, 결론과 행동의 above-the-fold 배치**다. 이 세 가지를 먼저 적용하면 현재 디자인 시스템을 거의 그대로 유지하면서도 프리미엄 인상이 크게 좋아진다.
