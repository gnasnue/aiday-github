## 문제
현재 하단 네비게이션 바의 각 탭(홈, 환경정보, 옷차림, 건강팁, 마이)을 클릭하면 페이지는 전환되지만, 스크롤 위치가 이전 페이지의 위치를 그대로 유지합니다. 사용자는 탭 이동 시 항상 해당 페이지의 최상단으로 랜딩되어야 한다고 요청했습니다.

## 원인
React Router의 `<Link>`는 기본적으로 페이지 전환 시 스크롤 위치를 복원/유지합니다. 각 페이지(`Home`, `Environment`, `Tips`, `Outfit`, `My`)가 독립적으로 동일한 하단 네비게이션 바를 구현하고 있으며, 어디에도 스크롤 초기화 로직이 없습니다.

## 해결 방안
`App.tsx`에 `ScrollToTop` 컴포넌트를 추가합니다. `useLocation`을 사용해 pathname이 변경될 때마다 `window.scrollTo(0, 0)`을 호출합니다. 이는 모든 라우트 전환에 일괄 적용되며, 각 페이지의 기존 코드를 수정할 필요가 없습니다.

## 수정 범위
- `src/App.tsx` only

## 검증
1. 빌드 통과 확인
2. 홈 → 환경정보 → 옷차림 → 건강팁 → 마이 순으로 탭 이동 시 각 페이지가 최상단에서 시작하는지 프리뷰에서 확인
